# 🎉 Happy Birthday Wish Website

An interactive birthday wish website built using HTML, CSS, and JavaScript. This project delivers a visually engaging experience with animations, styling, and dynamic behavior to create a memorable birthday greeting.

---

## ✨ Features

* 🎂 Interactive birthday interface
* 🎨 Clean and modern UI design
* 🎉 Smooth animations and effects
* ⚡ JavaScript-based interactivity
* 📱 Fully responsive layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## 💡 How It Works

1. The webpage loads the birthday interface
2. CSS handles layout and animations
3. JavaScript adds interactivity and dynamic behavior
4. User experiences an engaging birthday greeting

---

## ⚙️ Setup & Usage

1. Clone the repository:
   git clone https://github.com/pkpremshankar/Birthday-v-P03.git

2. Open the project folder

3. Run `index.html` in your browser

---

## 🎯 Customization

* Modify text inside `index.html`
* Update styles in `style.css`
* Enhance behavior in `app.js`
